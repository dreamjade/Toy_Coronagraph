Units#

Units of the scene components, and the conversion to one internal unit.

Two families:

physical   a brightness: any unit astropy converts to Jy (per pixel) or Jy/sr (per solid
           angle) with the spectral_density equivalency, e.g. Jy/arcsec^2, MJy/sr, W/m^2
           per pixel (nu F_nu), erg/s/cm^2/nm per pixel; and photons/s/cm^2/pixel over a band
relative   a fraction of the star's total flux: "contrast_pixel" (per pixel) or
           "contrast/arcsec^2"

The link between them is the star’s flux density F_star (Jy) at the wavelength.

Every component is first put per pixel of its own grid (so that resampling conserves the flux): Jy per pixel, or the fraction of F_star per pixel. The scene’s internal unit is then Jy/arcsec^2 when F_star is known (or every component is physical), else contrast_pixel.

class toycoronagraph.units.SourceImage(data, unit=None, pixel_scale=None, wavelength=None, band=None, origin='', notes=())[source]#

Bases: object

What a source module’s render() returns: an image, its unit and how to place it on the scene grid.

The image must be square and centred on the star (pixel (N-1)/2, rows = +y as in FITS).

Variables:

  • data (np.ndarray or astropy.units.Quantity) – (N, N) image; converted to float64 on creation. A Quantity’s unit replaces unit.

  • unit (str or astropy.units.UnitBase) – a NAMED unit (e.g. “contrast_pixel”, “Jy/arcsec^2”), PHOTONS, or anything astropy reads as a unit; a bare astropy unit without “/pixel” or a solid angle (e.g. u.Jy, dimensionless) is per pixel.

  • pixel_scale (float) – arcsec per pixel of data; None = already on the scene grid (the scene then sets it to the grid’s pixel scale).

  • wavelength (float) – m, the wavelength of a physical image (used by the spectral_density conversions); None = the scene’s wavelength.

  • band (tuple) – (lambda_min, lambda_max) in m, needed only for photon counts (PHOTONS).

  • origin (str) – text naming the image in messages (e.g. the file name).

  • notes (tuple of str) – messages for the user (shown with the scene’s notes).

Raises:

UnitError – when the unit is None and data is not a Quantity.

toycoronagraph.units.per_pixel(img, wavelength)[source]#

The image per pixel of its own grid, in the base unit of its family.

The unit is tried, in order, as a contrast per pixel, a contrast per solid angle (multiplied by the pixel area), a brightness per pixel (-> Jy with the spectral_density equivalency at the wavelength), and a brightness per solid angle (x pixel area -> Jy). Photon counts (PHOTONS) become Jy as F_nu = N h c / lambda / (c/lambda_min - c/lambda_max), i.e. the photons’ energy at the wavelength spread evenly over the band in frequency.

Parameters:

  • img (SourceImage) – with pixel_scale set (arcsec).

  • wavelength (float) – m, used when img.wavelength is None.

Returns:

(family, values): family is “physical” (values in Jy per pixel) or “relative” (values as the fraction of the star’s flux per pixel); values is a float64 array of the shape of img.data.

Return type:

tuple

Raises:

UnitError – photon counts without a band, an unknown unit, or a unit of neither family.
