Scene#

The scene: the image before the coronagraph, built from source modules.

scene = Scene.from_file("eps_eri.toml")                     # from a parameter file
scene = Scene(wavelength=500e-9, diameter=6.0, sampling=4, fov=2.0,
              star=Star(distance=3.22, radius=0.73))          # or in Python
scene.add(Wind(mdot=6e-13))                                  # any Source module, yours too
images = scene.render()                                      # {name: image}, and scene.total

Each component is rendered by its module (centred on the star, on its own grid, in its own unit), put per pixel (Jy, or the fraction of the star’s flux), resampled onto the scene grid with the flux conserved, and converted to the scene’s internal unit (units.choose_internal): “Jy/arcsec^2” when the star’s flux is known (or every component is physical), else “contrast_pixel” (the fraction of the star’s flux per pixel). Point sources (planets) are not images: they are kept as positions and fluxes (Scene.points).

Conventions: images are (N, N) float64 arrays with the star at pixel ((N-1)/2, (N-1)/2); rows are +y (upwards, as in FITS; plotted with origin=”lower”), columns +x; angles are measured from +x towards +y. The shared quantities (grid, wavelength, star) are resolved once by toycoronagraph.params.

Also here: the plotting helpers shared with toycoronagraph.observe (show_image, mark_points, point_labels, blank_panel, radial_profile, plot_profiles) and the scene FITS writer (write_scene, image_hdu).

toycoronagraph.scene.resample(values, scale_in, scale_out, size_out)[source]#

Resample per-pixel values onto another grid centred on the same star, conserving the flux.

The values must be per pixel (fluxes, not surface brightnesses): each input pixel’s flux is shared among the output pixels it overlaps, in proportion to the overlap area (integer factors give block sums). The 2-D overlap is separable, so it is one 1-D weight matrix w applied to both axes: w @ values @ w.T. Light outside the output grid is dropped.

Parameters:

  • values (np.ndarray) – (n_in, n_in) per-pixel values, star at pixel (n_in-1)/2.

  • scale_in (float) – Input pixel size in arcsec.

  • scale_out (float) – Output pixel size in arcsec.

  • size_out (int) – Output pixels on one edge.

Returns:

(size_out, size_out) float64 per-pixel values, star at pixel (size_out-1)/2.

Return type:

np.ndarray

render(verbose=True)[source]#

Render every enabled component onto the grid, in the internal unit.

Each module’s image is put per pixel (units.per_pixel), resampled onto the grid if it has another pixel size or field ([grid] resample), scaled by the component’s scale and converted to the internal unit. Point-source modules give positions and fluxes instead.

Parameters:

verbose (bool) – Print the notes and a one-line summary of the scene.

Returns:

{component name: (N, N) float64 image in self.internal_unit}; also sets self.total, self.points, self.internal_unit, self.star_flux, self.families, self.units, self.origins, self.component_of and self.notes (see the class docstring).

Return type:

dict

Raises:

  • ParamError – An image covers another field than the grid while [grid] resample = false.

  • UnitError – The components cannot be put in one unit (units.choose_internal).
