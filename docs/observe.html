Observe: a scene through coronagraphs#

A scene through one or more coronagraphs.

result = observe(scene)                              # the parameter file's coronagraphs and settings
result = observe(scene, ["vortex:2", "vortex:6"], combine="together")
result.final("vortex_c6")                            # the total; result.final("vortex_c6", "wind"): one component
result.save()                                        # results/<run>/: FITS per coronagraph, params_used.toml, plots

combine = “separate” (default): each component goes through each coronagraph with its own method (symmetric ones on the exact circular method, the others on the spatial one), and the final images are summed, each one kept. “together”: the components are summed first and go through each coronagraph once. Planets (point sources) always get their exact PSF. components=[…] restricts a run to some components (the spatial kernel size still comes from the whole scene, so separate runs add up to the combined one).

A Coronagraph holds one optical system on one grid: its PSFs (radial series and spatial models, cached on disk and in memory) and the final images it has made (cached by image), so only what changed is computed again. Coronagraph.get returns the same object for the same optics and settings, so Target (toycoronagraph.main) and observe() share these caches. optics_for turns a [[coronagraph]] table into its Optics, one builder per type (OPTICS_BUILDERS): “vortex” (hcipy) and “lazuli” (the Lazuli telescope computed with prysm, toycoronagraph.lazuli).

A Result holds the final images in the scene’s internal unit (“Jy/arcsec^2” or “contrast_pixel”); Result.save writes a run folder that Result.load reads back. Conventions: (N, N) images with the star at pixel (N-1)/2; rows are +y (as in FITS).

spatial_model(mode, weight)[source]#

The spatial PSF model whose kernel size meets the error target for an image.

The kernel size is chosen for weight (psf.choose_kernel_size; in ‘rotate’ mode from the cached radial PSFs, without new propagations) and cached per image, in memory and on disk (cache_dir/kernel_<tag>_<16 hex characters>.json, keyed by the image, mode and error target); a model already built with a larger kernel is reused (it is more accurate). The model itself (kernels, sample grid, blend weights, transmission map and error report) is cached on disk, cache_dir/model_<tag>_<mode>_K<kernel_size>_<16 hex characters>.npz, keyed by everything it is made from (_model_description, also stored in the file and compared when it is read: a file made from anything else is built again). Building one also caches the x-axis PSF runs and the error report (psf.spatial_error_report) on disk (cache_dir/axis_<tag>_K<kernel_size>.npz, cache_dir/error_<tag>_<mode>_K<kernel_size>_t<target>.npz), so a new session estimates nothing again.

Parameters:

  • mode (str) – “rotate” or “direct” (see psf.spatial_psf_calculation).

  • weight (np.ndarray) – (N, N) image whose light sets the kernel size.

Returns:

The model (see psf.spatial_psf_calculation; “kernel_size” is its kernel width in pixels).

Return type:

dict

property peak_norm#

The peak of the star’s unocculted PSF (the backend’s unocculted(): the optics without the starlight-suppression element, the Lyot stop kept), as a fraction of the star’s light per pixel: the contrast_peak reference. It is the intensity at the star’s position, so it does not depend on where the pixels fall (for an even N the star is between four pixels). Computed once; None if the backend has no unocculted().

Type:

float or None

property iwa#

The inner working angle, in lambda/D: the distance from the star at which a point source’s throughput (its light leaving the system relative to the same source without the starlight-suppression element, so 1 far from the star) reaches 0.5. It depends on the optics only, not on the image: it is searched along +x beyond the image’s edge if needed (to 64 lambda/D), by bisection to 0.01 lambda/D (about 15 sources, assuming the throughput rises with the distance); computed once. None when a source on the star already passes half (no coronagraph: e.g. the Lazuli telescope alone, charge = 0), or none reaches it by 64 lambda/D.

Type:

float or None

toycoronagraph.observe.video(scene, coronagraph, component, frames, path=None, fps=10, unit='contrast_peak', log=None, log_range=None, axis=None, dpi=None, iwa_ignore=False, difference=False, **kwargs)[source]#

A video of a scene through one coronagraph while one component changes, e.g. a CME moving outwards.

The scene is observed once, every component on its own with its current settings (combine = “separate”, whatever [method] combine says). Then, per frame, the component gets that frame’s settings (checked by its module), the scene is rendered again and only the component is observed again, with the method chosen the first time and the spatial kernel chosen for the first scene (its model comes from the caches: about one convolution per frame); the other components’ final images are reused. The colour scale is fixed by the first frame. The component gets its own settings back at the end. The video is lossless (toycoronagraph.video). A faint component (e.g. a CME against a stellar wind) shows with difference=True: each frame minus the other components’ final images, like the base-difference images (minus a pre-event image) that reveal solar CMEs against the corona.

Parameters:

  • scene (Scene) – The scene.

  • coronagraph (str or dict) – One coronagraph, as in observe() (e.g. “vortex:6”).

  • component (str) – The component that changes (an image, not a point source).

  • frames (list) – One dict per frame: the component’s settings in it, e.g. {“horizontal_height_factor”: 2.0}.

  • path (str) – The .webm file; None: <component>_<coronagraph name>.webm in the working directory.

  • fps (int) – Frames per second.

  • unit (str) – Output unit (see Result.in_unit; “contrast_peak”: relative to the coronagraph’s own peak).

  • log (bool) – Log colour scale. None here and below: the [display] setting.

  • log_range (float) – Log scale: decades shown below the first frame’s top.

  • axis (str) – Axis unit (see Grid.axis).

  • dpi (int) – Dots per inch of the 6.4 x 5 inch frames.

  • iwa_ignore (bool) – Leave out the light inside the inner working angle.

  • difference (bool) – Show only the component’s final image (the frame minus the others’).

  • **kwargs – Passed to matplotlib’s imshow, e.g. cmap=”magma”.

Returns:

(path, list of the (N, N) images shown, in unit, one per frame: the final image of all components summed, or with difference=True of the component alone).

Return type:

tuple

Panels: each one’s final image (one colour scale); their relative difference, (second - first) / first, where the first is within log_range decades of its peak (elsewhere grey), titled with its median and 99th percentile in absolute value; and the azimuthal means of the input and of both final images.

Parameters:

  • first (str) – Coronagraph names.

  • second (str) – Coronagraph names.

  • component (str) – Component name; None: the total.

  • unit (str) – Output unit (see in_unit); “auto”: self.unit. None here and below: the [display] setting.

  • log (bool) – Log colour scale and log-log profiles.

  • axis (str) – Axis / distance unit (see Grid.axis).

  • path (str) – Save the figure there; None: not saved.

  • show (bool) – Show the figure (else it is closed).

  • dpi (int) – Resolution of the saved file.

  • log_range (float) – Decades shown below the top of the colour scale, and kept in the difference.

  • star_flux (float or Star) – See in_unit.

  • **kwargs – Passed to matplotlib’s imshow for the two final images, e.g. cmap=”magma”.

Returns:

The figure.

Return type:

matplotlib.figure.Figure

save(folder=None, overwrite=None)[source]#

Save to a run folder (needs self.params).

Files written in the folder:

params_used.toml: the parameters used (Params.used_toml, with the coronagraphs and [method] settings).
scene.fits: the inputs (see scene.write_scene; primary header also STARFLUX in Jy, 0 if
    unknown, and PARHASH), and a POINTS binary table of the point sources (NAME, RADIUS
    arcsec, ANGLE rad, FLUX per pixel area in self.unit) if there are any.
<coronagraph>.fits: one per coronagraph; primary header CORONAG, OPTICS and the optics
    parameters (keywords cut to 8 characters, lists such as the wavelengths as comma-separated
    text), COMBINE, BUNIT, STARFLUX, PEAKNORM (peak_norms; 0 if unknown), IWA (arcsec, iwa(); 0: none),
    PARHASH (first 16 hex characters of the SHA-1 of params_used.toml); then FINAL_TOTAL (the sum of the others) and FINAL_<COMPONENT> images
    (with METHOD, MODE, ERRTYP and WHY, cut to 68 characters); with combine = "together", the
    final image of the summed images (component "total") is TOGETHER (TOGETHER_EXTENSION).
quicklook/finals.png (see plot), and quicklook/contributions.png when there are several
    components (see plot_contributions).
Parameters:

  • folder (str) – The run folder; None: [run] output_dir / [run] name (“auto”: the parameter file’s name, else “scene”).

  • overwrite (bool) – Write into an existing folder; else the new one gets _2, _3, …; None: [run] overwrite.

Returns:

The folder written (also self.folder).

Return type:

str

classmethod load(folder)[source]#

A saved result (for plots, contributions, other units), without computing anything again.

Reads scene.fits, params_used.toml and every other .fits file of the folder (one per coronagraph). Component names come back in lower case (from the FITS extension names; TOGETHER of a combine = “together” run is “total”); coronagraphs stays empty and tables / method_used are not restored.

Parameters:

folder (str) – A run folder written by save().

Returns:

The result; None if the folder has no coronagraph FITS file.

Return type:

Result or None
